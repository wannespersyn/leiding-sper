De Staftracker
App functionalities
Must have’s
1.	The main functionality is to keep track of how much everyone drunk in a certain period (mostly 3-4 months). We will work with points, so every consumption is one point.
2.	There are 2 categories:
a.	Beer
b.	Cocktail
These 2 have different point ratio, the beer ratio is one so one point is one point in general. But the cocktail is ratio 2, so one consumption counts for 2 in general.
3.	You can add a consumption to everyone’s account, this so that not everyone has to do it himself but that you just can click + for me and + for him
4.	There also has to be a subtle option somewhere where you delete a point because mistakes can be made.
5.	There must be also a profile page per person where you can see all the details.
a.	How much did I drink when
b.	How much points do I have this period
c.	A favourite drink
6.	There are different roles:
a.	Admin: will be explained later
b.	Leiding: the people of the organization.
c.	Extern: people that are not “Leiding” and will have to pay more.
d.	Scouts Rotselaar: this is a default person where there can be drawn points, so the rest doesn’t have to pay for them. This is where is being drunk “free” because we are working. 
7.	I also want an overview of how much everyone drank, in total and per day (only show days where there is being drawn points)
8.	The admin must have different functionalities:
a.	Export the list with the points to csv and or .xlsx and calculates the prices everyone must pay. So, there is little work for the admin.
i.	With how many beers
ii.	How many other
iii.	The price of the beer for extern and leiding
iv.	The price of the other for extern and leiding
b.	Also reset the period, so everyone starts with zero points. But the previous periods will still be shown until the admin deletes them.
9.	It must be an pwa, so we can easily access it.
10.	Search function
11.	QR code om nieuwe leden toe te voegen (optie voor leiding of extern)
Nice to have’s
1.	Favourites per account, so the people you most drink with are at the easiest reachable.
2.	Make a dark, light and system mode
3.	Notifications
a.	When an event comes
b.	When you must pay
c.	…
4.	Statistics
5.	Betaalstatus (als je hebt betaald duid je dat aan, en de admin kan dat confirmeren) en dan ook makkelijk zien wie nog niet heeft betaald van die periode.
6.	Achievements
a.	Eerste pint
b.	Eerste cocktail
c.	100 pinten
d.	10 dagen aanwezig
e.	Cocktailliefhebber
f.
